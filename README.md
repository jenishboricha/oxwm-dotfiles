# Roseppuccin OXWM Dotfiles

> *A minimal Arch Linux workstation built around **OXWM**, blending the
> aesthetics of **Rose Pine Moon** and **Catppuccin Macchiato**.*

------------------------------------------------------------------------

## About

This repository contains the configuration for a personal **Arch Linux**
workstation running **OXWM**.

The desktop combines the calm tones of **Rose Pine Moon** with carefully
selected **Catppuccin Macchiato** accents. This blend is affectionately
referred to as **Roseppuccin**---a lightweight, keyboard-first
workstation focused on consistency, simplicity, and everyday usability.

------------------------------------------------------------------------

## Components

``` text
OS         :: Arch Linux
WM         :: OXWM
Shell      :: Bash
Terminal   :: Alacritty
Launcher   :: Rofi
Notify     :: Dunst
Display    :: Ly
Browser    :: Firefox
Theme      :: Roseppuccin
Font       :: Iosevka
Icons      :: Rose Pine
```
