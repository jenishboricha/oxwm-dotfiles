# Roseppuccin OXWM Dotfiles

> *My minimal Arch Linux setup running **OXWM**—combining the calm vibes of **Rosé Pine Moon** with a few **Catppuccin Macchiato** accents.*

---

## About

These are my dotfiles for an **Arch Linux** desktop built around **OXWM**. 

I call it **Roseppuccin**—Rosé Pine Moon with Catppuccin Macchiato accents. Simple, fast, and looks good.

---

## Components

| Component | Choice |
| :--- | :--- |
| **OS** | Arch Linux |
| **WM** | OXWM |
| **Theme** | Roseppuccin |
| **Editor** | Neovim |
| **Terminal** | Alacritty |
| **Shell** | Bash |
| **Launcher** | Rofi |
| **Notification** | Dunst |
| **Compositor** | Picom |
| **File Manager** | Thunar |
| **Fetch** | Fastfetch |
